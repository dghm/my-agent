Primary action control — use `primary` (near-black) for the single main action, `secondary` (outlined) for alternatives, `ghost` for tertiary, `inverse` on dark surfaces.

```jsx
<Button variant="primary" size="md" onClick={save}>Contact us</Button>
<Button variant="secondary">Learn more</Button>
```

Variants: primary | secondary | ghost | inverse. Sizes: sm 28px, md 36px, lg 44px. Sentence-case labels, never uppercase.
