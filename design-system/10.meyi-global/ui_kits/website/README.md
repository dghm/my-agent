# Website UI Kit — Meyi Global

**Modelled, not sourced.** No product codebase, Figma, or live site was provided; this kit is an original corporate-marketing-site treatment built strictly from the brand tokens and logo assets. Replace copy and structure with real content when available.

- `index.html` — interactive click-through (Home / Services / Contact, working nav, form validation, sent dialog)
- `SiteChrome.jsx` — SiteHeader (sticky, logo + uppercase nav + CTA) and SiteFooter (pure black)
- `HomeScreen.jsx` — ink hero, services card grid, contact band
- `ServicesScreen.jsx` — tabbed service detail with inverse CTA card
- `ContactScreen.jsx` — two-column contact form using Input/Select/Checkbox/Button/Dialog

All primitives come from the compiled design-system bundle (`window.MeyiGlobalDesignSystem_830a18`); nothing is re-implemented here except page-level layout.
