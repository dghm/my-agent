DGHM Card / Tag / Stat — surfaces and data highlights following the four brand combos.

```jsx
<Card tone="brand"><h3>先診斷・再設計</h3></Card>
<Tag tone="accent">CRM</Tag>
<Stat tone="accent" value="+38%" label="流程效率提升" />
```

Card tones map to 配色組合: default(白底), section(淡藍灰), brand(深藍), accent(橘). Never navy text on accent.
