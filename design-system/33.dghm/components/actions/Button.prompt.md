DGHM Button — use for all clickable actions; primary variant is the brand's orange CTA (always white text, never navy on orange).

```jsx
<Button variant="primary" size="lg">立即諮詢 →</Button>
<Button variant="outline">How it works</Button>
```

Variants: `primary` (orange CTA — max one per view region), `secondary` (navy), `outline`, `ghost`. Sizes sm/md/lg. Hover darkens (`--cta-bg-hover` #C04E1E).
